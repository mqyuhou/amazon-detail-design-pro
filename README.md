# Amazon Detail Design Pro Skill

一个用于 Amazon 产品详情页分析、拆解和设计方案生成的 AI Skill。

## 功能介绍

Amazon Detail Design Pro 可以帮助卖家、设计师和运营人员：

- 分析优秀 Amazon Listing 详情页结构
- 拆解竞品图片布局和营销逻辑
- 生成产品详情页设计规划方案
- 规划主图、A+、功能图、场景图结构
- 输出视觉设计 Brief 和 AI 图片生成提示词
- 根据修改意见进行详情页优化迭代


## Skill 工作流程

1. 分析参考详情页

- 提取页面结构
- 分析图片模块顺序
- 识别卖点表达方式
- 总结视觉策略


2. 制定新品详情页方案

- 产品定位分析
- 用户购买决策路径设计
- 图片模块规划
- 文案和视觉方向制定


3. 输出设计指导

生成：

- 页面布局方案
- 图片设计要求
- 视觉素材 Prompt
- 优化修改建议
